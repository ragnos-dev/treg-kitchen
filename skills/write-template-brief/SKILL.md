# Write a brief in the supplied template

1. Confirm the template is readable and identify the supplied recordings, transcripts, and notes. Prefer usable transcripts. If an approved transcription method is needed, keep the filename and timestamps with each transcript and flag uncertain words or speakers. If access, transcription, or the template is missing, name the dependency and work through the available material.
2. Read the template before drafting. Preserve the section order and honor its field instructions. Identify which source passages support each decision, fact, action item, and unresolved question. Use the timestamps when available. Otherwise use a filename and a section or paragraph locator.
3. Fill the template with what the evidence establishes. Keep decisions separate from proposals. Record an owner or deadline only when the source establishes it. Mark required entries without evidence as unresolved and explain what would fill each one. Surface material discrepancies between recordings or notes.
4. Review the draft against the template and verify that each material claim traces to a supplied source. Return the completed draft, the source locators (inline or in a separate evidence note if the template requires a clean draft), and open items for the reviewer. Keep private source material in the approved environment.
